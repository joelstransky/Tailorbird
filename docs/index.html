Engineered for Job Seekers Who Value Speed and Privacy

Stop wrestling with repetitive web forms, clunky browser extensions, and scattered spreadsheets.

⚡

Resilient ATS Autofill

Custom multi-modal heuristics that accurately populate text inputs, dropdowns, radio groups, and pronoun selectors across Greenhouse, Lever, Ashby, and Workday.

⚠️

Unfilled Fields Tracking

Never miss a required question. Unfilled interactive fields are highlighted with warm amber accents, paired with a persistent live countdown toast that confirms when your form is 100% complete.

📄

Intelligent Resume Parser

Directly scan local PDFs, Markdown, JSON, or public Google Docs. The heuristic parser isolates dates, companies, and roles while preserving bullet achievements without splitting errors.

📊

Built-in Prospect Sheet

One-click page scraping records company names, job titles, and application URLs directly into an integrated pipeline sheet with status stages, inline cell editing, and CSV export.

🔍

Boolean Search Synthesizer

Assemble laser-focused boolean queries targeting live postings on Greenhouse, Lever, LinkedIn, Indeed, and Google Jobs without search syntax collision.

📋

Special Fields & Paragraph Snippets

Save custom answers to common open-ended application prompts (e.g. "Why do you want to work here?") in dedicated text areas with instant 1-click clipboard copying.

🔒

Zero Telemetry, 100% Local

Your personal resume data, phone number, work history, and prospect pipelines remain entirely on your local machine in JSON format. No third-party servers, no analytics, no subscription traps.

Get Started in Minutes

Tailorbird runs natively on Windows, macOS, and Linux using Rust's official toolchain.

Terminal (PowerShell / Bash) Rust 1.75+ 
# 1. Clone the repository
git clone https://github.com/joelstransky/Tailorbird.git
cd Tailorbird

# 2. Run the application in development mode
cargo run

# 3. Or compile an optimized production binary
cargo build --release
# Executable is generated at target/release/tailorbird
